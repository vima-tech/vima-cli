# lore · 经验沉淀位

**本轮只留位置，不预建内容。**

这里放做过一遍才知道的东西：某个宿主的坑、某类需求的惯例、某次踩过的坑和它的判据。
它和另外三类资产的分工：

| 放哪 | 什么东西 | 判据 |
|---|---|---|
| `style/` 令牌与词表 | 形。合法产出长什么样 | 写不出非法的东西 |
| `blocks/` 业务块 | 料。现成的成品 | 装上就能用 |
| `rules/` 规则 | 纪律。下沉不了的判断 | 需要人判断 / 约束怎么用工具 |
| `lore/` 经验 | **回顾产生的东西** | 做过一遍才知道，且还没稳定到能变成上面三者 |

## 为什么不预建

预建的「经验」是假经验——它没有来源、没有代价、没有当时的判断，
读的人无从判断它还成不成立，于是只能全信或全不信，两种都比没有更糟。

经验必须从真实回顾里长出来，带着「哪次踩的、代价是什么」。
一条经验稳定复现之后，它的归宿是**往下沉**：能变成词表的加词，
能变成机检的写检查，两者都不行才留在 `rules/`。
留在 `lore/` 里的，是还没到那一步的。
