# 需要裁定的事先定夺，别停下来等

遇到规格没说清、两种做法都说得通的分歧：

1. **不要停下来问**，也不要挑一个偷偷做掉；
2. 自己定夺，记成一条裁定，带上 `confidence`（多有把握）
   与 `blastRadius`（判错了要改多少）；
3. 继续往下做。人看到台账后可以二次裁决，走的是同一条失效传播链路。

## 两个字段不是装饰

没有优先级的裁定台账，结局和「永远消不掉的告警」一样：条目越攒越多，
最后没有人看。`confidence` 低 + `blastRadius` 大的那几条，才是需要人先看的。

## 为什么留在规则层

「这算不算需要裁定的分歧」「有多大把握」只能当场判断。
机制层已经做了它该做的：裁定有专门的事件种类，台账是自动生成的，
人不需要记得去记录——但**判断本身**下沉不了。
