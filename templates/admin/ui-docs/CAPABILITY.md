## 函数式 API（非组件）

以下服务同样从 `@vima-tech/ui-admin` 导入，命令式调用，无需模板标签：

| API | 说明 |
|---|---|
| `layer` | 轻量弹层服务，API 形状与 Layui layer 一致：`layer.msg()` / `layer.notify()` / `layer.confirm()` / `layer.load()` / `layer.close()` / `layer.closeAll()` |
| `message` | 全局消息提示：`message.info/success/warning/error(content, duration?)` / `message.open(options)` / `message.closeAll()` |
| `messageBox` | 模态对话框（Promise 风格）：`messageBox.alert/confirm/prompt(message, title?, options?)` → `Promise<'confirm'\|'cancel'\|'close'>` |
| `getIconNames` | 返回全部已注册图标名列表 |
| `hasIcon` | 判断指定图标名是否已注册 |
| `iconSvgMarkup` | 返回指定图标的内联 SVG 字符串 |
| `normalizeIconName` | 归一化图标名写法（别名/大小写） |
| `registerIcon` | 注册自定义图标（名称 + SVG） |
