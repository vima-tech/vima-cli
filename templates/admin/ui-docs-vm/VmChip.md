# VmChip · 状态标签

> 类：`vm-chip`

## 用途

胶囊状的状态/计数标记。**状态一律用它表达**，不要靠改文字颜色。

## 结构

```html
<text class="vm-chip green">已完成</text>
<text class="vm-chip amber">待提交</text>
<text class="vm-chip red">已逾期</text>
```

## 修饰类

| 类 | 语义建议 |
|---|---|
| 不写 | 蓝：中性、进行中 |
| `green` | 完成、正常、达标 |
| `amber` | 待办、提醒、临界 |
| `red` | 异常、逾期、失败 |
| `cyan` `indigo` `violet` | 分类标记（无固定语义，同一项目内保持一致） |

## 不要这样用

- **一行里最多两个 chip**。三个以上就该重新设计信息层级。
- **文案控制在 4 个字内**：胶囊不换行，长了会把标题挤成逐字折行
  （适老化放大后尤其明显）。
