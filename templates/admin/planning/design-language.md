## 1. 不变层（与场景无关，不参与推导）

一句话骨相：**克制的专业工具感**——层级靠字重与留白建立，不靠装饰堆叠。

无论做医院系统、政务平台还是车间看板，下面八条都成立。**它们不是缺省值，是准则**
——推导只决定「多少」，不决定「要不要」。

| # | 准则 | 为什么（反查依据） |
|---|---|---|
| 1 | **不用渐变顶栏、不用网格底纹** | 渐变 + 网格是 2015–2018 年的「科技感」语汇，今天读作旧 |
| 2 | **描边优先于投影分层**：1px 半透明描边 + `0 1px 2px` 微投影封顶 | 大范围柔化投影（`0 14px 30px -24px` 那类）是拟物余韵 |
| 3 | **语义色同明度带**：success/warning/error/info 四色明度差 ≤ 8 | 明度不齐会让同一行状态标签看着有轻重之分 |
| 4 | **标题字重 ≤ 700** | 800 在中文字体下过厚，是「老后台」的签名 |
| 5 | **数字一律 `tabular-nums`** | 指标、编号、时长、金额全是对齐场景，比例数字会跳 |
| 6 | **单一品牌色**：一个品牌色 + 一组语义色，不设第二品牌色 | 两个品牌色必然打架，且让语义色失去辨识度 |
| 7 | **深色只作「锚」，不作全局** | 组件库 `ui.css` 141 处浅色裸值，全深色主题落不了地；且久看疲劳 |
| 8 | **字体不下载 webfont**，只用系统/预装字体 | 首屏不闪、离线可用——这是取向也是硬约束 |

> 第 7 条的落地边界（**实测，非估计**）：外壳（`shell.css`）与业务页可 100% 换肤；
> 组件配色靠库暴露的 34 个 `--vui-*` 令牌；**组件圆角完全动不了**（库无 radius 令牌，
> 20 种取值硬编码）——所以下面推出的圆角档**只写外壳与卡片**，控件仍是库的 4–14px。
> 另有 `alert/badge/message/message-box/step` 共 16 个类硬编码 Ant 四色，换主题时需项目侧覆盖。

## 3. 推导规则（观察量 → 取向轴档位）

按序套用。每条只看指定的观察量，**不掺其他判断**；两条冲突时以序号小的为准并在
§7 注明冲突与裁定。

| 规则 | 条件 | 结论 |
|---|---|---|
| **R1 深色锚位置** | O1 全天候 且 O3 暗环境 | 顶栏 + 侧栏同深（内容区仍浅） |
| | O1 工作时段，或 O1 全天候但 O3 常规办公 | 仅顶栏深 |
| | O4 面向公众或监管 | 无深锚——顶栏用品牌纯色 |
| **R2 强调手法** | O2 秒级 | 色彩优先（状态靠色，一眼可辨） |
| | O2 分钟级及以上 | 字重留白优先 |
| **R3 内容密度** | O5 表格清单主导 且 常用列表单页 > 20 行 | 紧凑 |
| | O5 表单录入主导 | 均衡 |
| | O4 面向公众 | 舒展 |
| **R4 容器化程度** | O5 指标时序主导 | 万物皆卡 |
| | O5 表格清单主导 | 主次分卡 |
| | O5 表单录入主导 | 少卡分区（分隔线 + 小标题，别拿卡当分节符） |
| **R5 形状性格** | O4 面向公众或监管 | 方正 8 / 6 |
| | O2 秒级（实时监控类） | 中性偏紧 10 / 8 |
| | 其余 | 中性 12 / 10 |
| **R6 装饰度** | 一律「仅主视觉」 | 例外只有一种：O4 = 对外展示/大屏，可升到「主视觉 + 关键卡」 |
| **R7 底色温度** | O4 面向公众或监管 | 暖中性灰（冷灰偏科技消费品，暖灰更像机构） |
| | O3 强光或车间 | 冷中性灰 + **提高底色与卡面的明度差**（强光下低对比看不清） |
| | 其余 | 冷中性灰 |
| **R8 触达尺寸** | O6 触摸屏 或 混合 | 控件最小触达 44px，且 **R3 不得取「紧凑」**（冲突时本条优先） |

**R3 的「内容密度」与 PDL `density` 不是一回事，别混**：

- R3 推出的**内容密度**是整体倾向——「一屏该放多少信息」，它决定各页 `design.density` 的**缺省选择**；
- PDL 的 `density: compact | default | loose` 是**间距档**，作用在具体页/块上，落到
  `.vui-density-*` 类，只重定义 `--v-gap-*` 一族。

对照：内容密度取「紧凑」→ 页面缺省 `density: compact`（表格类块尤其）；取「舒展」→ 缺省 `loose`。

## 4. 色彩纲领（唯一带主观余地的一步）

品牌色相是全套里最难判定的一处，所以给三条判据把余地收窄：

1. **从行业语义取色相**，不从喜好取。例：医疗器械与生命体征 → 青／teal（180–195°）；
   公检法 → 藏青（210–220°，但降饱和）；食品与农业溯源 → 绿（130–150°）；
   工业制造 → 中性蓝灰打底 + 琥珀作强调（40–50°）。
2. **与 O7 的行业默认色相相距 ≥ 30°**。这是「有别于老系统」最有效的单点改动——
   老系统的辨识度大半来自那个用了二十年的色相，避开它比改任何形状都管用。
3. **语义色由品牌色反推明度带**：四色取同一明度带（L 差 ≤ 8），饱和度不高于品牌色。

三条都满足后，把取值填进 §7。若与 O8 色彩禁忌冲突，**禁忌优先**。

## 5. 旧信号清单（什么算「不现代」）

定完档，用这张表回查自己有没有把旧手法带进来。**可 grep**：

| 旧信号 | 检法 |
|---|---|
| 渐变顶栏 | `grep -n "linear-gradient" src/styles/shell.css` 命中顶栏区即中招 |
| 网格 / 条纹底纹 | `grep -n "repeating-linear-gradient" src/styles/` |
| 大柔化投影 | `grep -nE "box-shadow:[^;]*[0-9]{2}px [0-9]{2}px" src/styles/` |
| 800 字重 | `grep -n "weight-title: 800\|font-weight: *800" src/styles/` |
| iOS 6 时代语义色 | `grep -nE "#4cd964\|#ff3b30\|#ff9500" src/styles/tokens.css` |
| 裸色值 | post-write hook 已拦；`grep -nE "#[0-9a-fA-F]{6}" src/views/` 应为 0 |
| 密集边框表格 | 表格每格都有 1px 线 = 旧签名；只留行分隔 |
| 直角 + 小字 + 高饱和大色块 | 三者同现基本可判定为老政务/老 HIS 观感 |

## 6. 自检判据（定完档跑一遍，不进 validate）

1. **对比度**：正文与底色 ≥ 4.5:1，大字与图标 ≥ 3:1（WCAG AA）；
2. **语义色明度带**：四色 L 差 ≤ 8；
3. **色相距离**：品牌色与 O7 行业默认色相相距 ≥ 30°；
4. **深锚占比**：顶栏 + 侧栏在 1920×1080 下占屏 ≤ 25%；
5. **旧信号**：§5 全表零命中；
6. **触达**：O6 含触摸屏时，实测控件命中区 ≥ 44px。

这六条是**人工/Agent 自检清单**，刻意不做成 CLI 规则（D-A30-05：主观取向机检不出来，
假机检比没有更坏）。但第 1、3、5 条可以写成一次性脚本跑，值得跑。

## 8. 参考范例（三份已推导样本）

不是可选菜单，是**方法论的用法示范**——看同一套规则在不同观察量下推出什么。
**不得直接套用**：新场景一律自己照 §2→§3→§4 走一遍，哪怕行业看着一样。
（照搬范例 = 退回「挑一个最像的」，那正是本方法要治的病。）

### 范例甲 · 冷光临床（医院 HIS 周边：营养管理、手术麻醉、随访）

- 观察量：O1 工作时段 · O2 分钟级 · O3 常规办公 · O4 内部作业 ·
  O5 表格清单主导 · O6 鼠标 · O7 HIS 宝蓝 217° · O8 红色专用于危急
- 推导：R1→仅顶栏深 · R2→字重留白优先 · R3→紧凑 · R4→主次分卡 ·
  R5→中性 12/10 · R6→仅主视觉 · R7→冷中性灰
- 色彩：品牌青蓝 `#0E8C9C`（190°，与 217° 相距 27°→ **微调至 `#0C8FA6`（193°）满足 ≥30°**）；
  深锚 `#0E1A20`；页底 `#F5F7F8`
- 气质：冷光、精密、轻盈——像高端医疗设备的操作台，不像医院的信息系统

### 范例乙 · 深空控制台（急诊分诊、手麻监护、MES 车间看板）

- 观察量：O1 全天候值守 · O2 秒级 · O3 暗环境 · O4 内部作业 ·
  O5 指标时序主导 · O6 混合 · O7 监护设备深蓝黑 · O8 红黄绿为分级专用
- 推导：R1→顶栏+侧栏同深 · R2→**色彩优先** · R3→紧凑，但 **R8 触摸屏优先→回退均衡** ·
  R4→万物皆卡 · R5→中性偏紧 10/8 · R6→仅主视觉 · R7→冷中性灰
- 色彩：品牌 `#3B82F6`；危重 `#D64550` / 警戒 `#DD9B23`；外壳 `#0B1220`；内容底 `#F3F5F8`
- 气质：驾驶舱——信息在流动，状态在呼吸。**唯一允许辉光的档**，且辉光只给主操作与实时状态

### 范例丙 · 磐石政务（政府、公安、溯源监管、MES 管理端）

- 观察量：O1 工作时段 · O2 小时以上 · O3 常规办公 · O4 **面向公众或监管** ·
  O5 表格清单主导 · O6 鼠标 · O7 政务深蓝渐变 210° · O8 无
- 推导：R1→**无深锚**，品牌纯色顶栏 · R2→字重留白优先 · R3→紧凑 · R4→主次分卡 ·
  R5→**方正 8/6** · R6→仅主视觉 · R7→**暖中性灰**
- 色彩：品牌藏青 `#1E3A5F`（降饱和，色相同域但**去渐变去投影**以拉开距离）；
  页底 `#F5F5F3`；投影 **全零**
- 气质：权威、正式、秩序——现代但不轻佻。与旧政务的区隔不在色相在手法

> 范例丙是个有用的反例：**当行业色相本身就是权威符号时（藏青），R4-2 的「相距 ≥30°」
> 让位于 O8 类的语义约束**——改走「同色相、换手法」的路子（零渐变 / 零投影 / 方正 /
> 大留白）。方法论允许这种裁定，但**必须写进 §7 的「规则冲突与裁定」**。
